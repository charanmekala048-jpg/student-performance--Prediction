# Student Performance Prediction using Linear Regression

## Objective
To predict student marks based on study-related factors such as hours studied, attendance, previous scores, and assignments completed.

## Description
This project uses Linear Regression to estimate student performance. It helps in analyzing which factors affect marks and how well student outcomes can be predicted.

## Algorithm
Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Outcome
The model predicts student performance and helps identify the importance of academic factors in determining final scores.
